### Предварительные наблюдения (этап 2)

- Все 36 квестов из снифа есть в TDB, у всех есть стартер и эндер; совпадают со снифом, кроме 54952 (в снифе сдаётся NPC 156651, в TDB — 156607).
- В снифе 159 разных фаз; в TDB по этим ID есть 46 записей `phase_area`, 36 используются спавнами острова, 46 имеют условия фаз.
- WPP выгрузил 1233 спавна существ, 112 объектов, 72 разговора, 45 текстов, 83 записи spawn tracking, 12 сцен.

### Итоги сверки (этап 3)

- Квесты: все 36 совпадают с TDB (шаблоны и цели); расходится только эндер 54952.
- Существа: 871 совпадает (из них 136 бродячих, увидены в другой точке пути), 177 есть только в снифе, 131 только в TDB.
- Объекты: 31 совпадает, 17 только в снифе (травы, сундуки, костры, двери Darkmaul), 11 только в TDB (лагерь Орды, тотемы, катапульты).
- Фазы: 159 в снифе, 46 есть в `phase_area`; 113 без `phase_area` (часть — глобальные/косметические); 24 фазы спавнов TDB в снифе не встречались.
- Тексты: у 21 говорящего существа нет `creature_text` (Гневион, Джайна, Калесгос, Генри Гэррик, Мереди, огры и др.).
- Разговоры: 40 из 72 шаблонов и 75 из 133 реплик отсутствуют; скрипты острова на них пока не ссылаются.
- Сцены: все 12 есть.

Как отбирались данные:

- Спавн считается недостающим, если в TDB нет того же entry ближе 3 ярдов (и бродячего двойника ближе 25 ярдов). Пассажиры корабля Альянса лежат на карте транспорта 2261 в локальных координатах, как в TDB.
- Не взяты: 58 пассажиров судна на Драконьи острова (карта 2444) и 4 дубля одного спавна.
- Фаза спавна выводится из снифа (колонка `PhaseId` WPP — это фазы игрока, а не спавна): объект появился сразу после добавления фазы / исчез при её снятии; иначе фаза как у спавнов TDB того же entry; иначе самая «узкая» из активных фаз (помечено `guess` в комментарии строки). Сокровища — без фазы. Проверить на этапе 5.
- `MovementType`: как у спавнов TDB того же entry (путь → стоит на месте); для новых entry бродячие мобы — радиус 5. Пути (`waypoint_path` в выгрузке WPP) пока не импортированы — этап 6.
- `creature_text`: текст — enUS из `broadcast_text`, ID найден по русскому тексту/звуку. Скрипты эти тексты пока не используют — этап 6.

Осталось вне SQL (на этапы 5–6):

- 11 реплик без `BroadcastTextId` (в 12.x клиентский BroadcastText.db2 почти пуст, тексты идут хотфиксами, а их в снифе нет): огр-повар 154103, эмоуты боссов 156501/157300, освобождённый участник экспедиции 160964 (4), 162817, 194652. Реплика Гневиона 290995, которую WPP приписал Торгоку 162817, отброшена.
- 26 актёров разговоров — личные призывы игрока (спутники); их должен подставлять скрипт, запускающий разговор.
- В цепочках `ConversationLine.db2` 12.1 есть реплики, которые retail этому персонажу не присылал (36498, 36534–36546, 36692–36694, 36701–36702): шаблонов у них нет, ядро их пропускает с ошибкой в `DBErrors.log` — поведение как в retail.
- Разговоры 12851 и 12958: retail присылает реплики 82403/88049, а ядро по `NextConversationLineID` (uint16) уходит в 16867/22513 — хак в `ConversationDataStore.cpp` срабатывает только для реплик с ID > 60000. Нужна правка ядра.

### Этап 5: фазы и условия

Файл `2026_10_27_03_world_exiles_reach_phases.sql` (идемпотентный): `phase_area` и условия фаз (`conditions`, SourceType 26) для 19 фаз. Бэкап перед этапом: `build/db_backups/world_phase_before_stage5_20261027.sql`.

Как проверялось:

- Из снифа взяты 78 состояний фаз игрока на карте 2175. К каждому — состояние всех квестов, ауры игрока и подзона. Подзона считается по позиции игрока из пакетов движения и сетке областей `.map`-файлов сервера, как в ядре (`SMSG_INIT_WORLD_STATES` приходит не на каждую смену подзоны). Снимки, когда игрок давно не слал позицию (транспорт), не учитываются.
- Правило фазы (подзоны `phase_area` + условия) проверяется на всех снимках; допускается 1 промах на границе подзон (WMO-области сетка не видит).
- Из 159 фаз снифа спавны острова используют 85; остальные — клиентские/косметические, их не трогаем. 38 фаз спавнов в снифе не встречались (Орда, другие классы) — тоже без изменений.

Что изменено:

| Фаза | Было (TDB) | Стало | Промахов TDB → после |
|---|---|---|---|
| 13328, 13393, 14353, 14987, 15473 | нет `phase_area` (их используют новые спавны этапа 4) | добавлены правила по квестам 55764/55991, 55186, 58208, 55882, 56344 | — → 0–2 |
| 13809, 13832, 15011, 16752 | не хватало подзоны | добавлены 10527 / 10568 / 10503 | 2–4 → 0–2 |

| 13835, 15017, 15276, 15356, 13878 | действовали на весь остров | только свои подзоны (равнины, руины огров, лагерь свинобразов) | 18–54 → 0–6 |

- Для Орды старые правила TDB сохранены отдельной OR-группой с условием `team 67`, если они ссылаются на квесты, которых нет в снифе Альянса (6 групп). Правила, полностью построенные на квестах Альянса, заменены.
- Катапульты 90010001–90010004 переведены из фазы 13839 в 13840: в снифе они появляются ровно при добавлении 13840.
- Оставшиеся промахи (13878, 15356 — до 6) приходятся на поездки на скаут-о-мате/кабане, когда позиция игрока в снифе не обновляется.

Не тронуто, на проверку в этапе 7:

- Фазы равнин 13766, 13775, 13776, 13779, 13780, 13785: расхождения только во время поездок на транспорте.
- 13753, 14350 (корабль), 13834, 13836, 13840, 14695, 15473: переключения внутри одной подзоны (пещера/WMO) — по сетке не различить.
- Спавны TDB, фаза которых не была активна, когда сниф их видел: кабаны 1051572/1051547, олененок 1051568, Генри Гэррик 1051899 и Кии-Ла 1051900 (13318), руны огров 90010005–90010007, Келра 90010008, знак 600229 — однозначной замены сниф не даёт.
